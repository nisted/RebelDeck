Help

  
Everything RebelDeck does, in one place. Hover over almost anything for a tooltip too.

  

    
What is it?

    
Virtual Stream Decks for Companion: in their own floating windows, on a Pi's screen, or in any browser on your network.
      A rebuild of Joseph Adams' ScreenDeck, given a good shake.

    
Three ways in

    
  • Tray icon: status, the pop-out, this page, show/hide each deck, identify a deck, update, quit.
    • 
      
  • Pop-out: the quick stuff: start at login, which decks are open, phone QR code.
    • 
      
  • This page: everything else.

    
Companion side

    
Nothing to install. RebelDeck uses Companion's Satellite API (Companion 3.5 or later; faders need 3.4+ variables, smooth turning needs 5.1+).
      Each deck appears in Surfaces as a Satellite surface with an id starting rebeldeck.
      Give it a page, offset and the rest there, like any Stream Deck. Renaming or resizing a deck keeps its Companion setup.

    
Deck windows

    
  • Window open switch: opens or closes the deck's window on this computer.
    • 
      
  • Float: the window stays on top of everything else. Also on the window's own header.
    • 
      
  • Movable: off locks the window where it is (no dragging, no resizing).
    • 
      
  • Drag the window by its header. Resize it with the corner grip: it keeps the deck's shape, so no letterboxing. It remembers where it was.
    • 
      
  • Colour and see-through: the window's background. On Windows, see-through fades the whole window (buttons too); on Macs and Pis just the background.
    • 
      
  • Companion's surface brightness dims the buttons only, never the window.
    • 
      
  • Identify (here or in the tray) flashes the deck's name and brings it to the front, so you can find it.

    
The button editor

    
  • Clickable: every button works. Unclickable: the deck just shows. Hybrid: you pick.
        Switching to Hybrid starts with every button off (red ✕); click buttons to make them work, or use Select all / Deselect all.
    • 
      
  • Key type: paint buttons as Button, Rotary or Fader.
        Rotaries: drag left/right or use the scroll wheel to turn; a quick tap pushes.
        Faders: drag up and down. They work like the Intech Grid's, in two ways:
        turn steps go to the button at that spot on Companion's current page (give it rotate left/right actions, as for a
        Stream Deck + dial: Companion has no "fader" button type), and the fader's position, 0-127, is a surface variable
        fader_N that's the same whichever page you're on. Companion can move the fader with fader_N_set.
        Companion's docs don't say where a Satellite surface's variables show up; look in the deck's surface settings in Companion.
    • 
      
  • Gap: an empty space with nothing to press, as Companion leaves on a + XL.
    • 
      
  • Strip row: the whole row becomes wide, short buttons, like a Stream Deck + touch strip. Strip shape sets
        how wide (2 = twice as wide as tall). Wide pictures need Companion 5; older ones send square pictures.
    • 
      
  • Strip rows and gaps use Companion's newer free layout (Companion 4.2+); the presets for the + and + XL
        are laid out as Companion lays out the real ones.
    • 
      
  • One key-type layout per deck, whatever Companion page is showing: a fader on a button with no rotate actions does
        nothing, and can't press that button.
    • 
      
  • Break out: click a button to give it its own little floating window, anywhere on screen. It keeps its place in Companion.
        Click again (or close its window) to put it back.

    
Browsers, phones and tablets

    
Each deck has its own address, from its name (/deck/foh-mini), and a short one from its number on the Decks
      page (/1, /2…). Deleting a deck moves the ones after it up a number (you're warned first). Renaming a deck changes its address, so bookmarks and
      home-screen icons need redoing. The pick-a-deck page (/) lists every deck on this computer and on other RebelDecks
      it can hear on the network. See the Browsers page for the address, QR code and .local name.

    
A deck's QR code on a Companion button

    
Add a Generic: HTTP Requests connection in Companion, then give a button its Image from URL feedback with
      http://<this computer>:8091/api/decks/<deck>/qr.png (the deck's address name, e.g. foh-mini).
      The pick-a-deck page's code is /api/qr.png. Point a phone at the button and you're in.

    
Several Companions

    
Add them on the Companion page and pick a default. Flip a deck's Own Companion switch to send it somewhere else.

    
Profiles

    
Save the whole set of decks under a name, and load it back later. Loading replaces the current decks.

    
Known limits

    
  • A press always ends with a release in Companion, even if you slide off the button first: Companion's Satellite API has no
      "cancel". Put actions you might want to abort on press, not release.
    • 
      
  • On Pi desktops that use Wayland, Float and remembered positions may not work (Wayland doesn't let apps do that).
